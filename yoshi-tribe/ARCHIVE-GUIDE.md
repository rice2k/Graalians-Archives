# Yoshi Tribe Archive — Detailed Guide

## Purpose
This directory documents and preserves surviving material from the GraalOnline Yoshi Tribe community and related sites. The source collection combines recovered historical pages with newly built offline navigation and research tools.

## What is in the source archive
- 42 recovered news posts
- 187 recovered message-board posts
- 14 identified board members
- 28 board topics
- 134 readable captures
- 66 gallery images
- 357 raw files
- 2,348 source URLs

## Major sections
### Original/restored site
The restored period-style Yoshi Tribe homepage preserves the older layout, navigation, news and links while adding an offline archive toolbar.

### Search
A generated search index covers reconstructed pages, recovered news, board threads, member pages and readable site captures. The full source search page is roughly 468 KB.

### Timeline
The timeline combines news, board activity and captured site versions by date. Surviving material spans the original 2000s-era activity and later archived captures.

### News
The news browser collects recovered Yoshi Tribe news items from archived homepage captures and supports filtering by author, year and title.

### Message board
The archive contains 187 unique recovered messages across 28 topics and identifies 14 known board members.

### Yoshi Valley
Related Yoshi Valley material is included as a companion archive where recovered.

### Alzabo / Dino Valley Central
The source collection also preserves Alzabo Tripod and Dino Valley Central material, including surviving captures and references to files that were named but not preserved.

### Site versions
Captured versions are retained so historical changes can be compared rather than silently merged into a single reconstruction.

### Provenance
Archive-created pages should remain distinguishable from recovered historical material. Status labels used by the source project include recovered, reconstructed and missing.

## Privacy and publication policy
The source archive can contain historical usernames, old contact details, forum text and other material copied from archived public webpages. This GitHub repository is public, so migration should be selective. Sensitive credentials, private account data, non-public personal information and material that should not be republished are not intentionally added here.

GitHub does not provide private files inside an otherwise public repository. Material that needs to remain private must stay outside this repository or be placed in a separate private repository.

## Migration status
The archive is being migrated in verified batches. Large generated indexes and raw preservation files are kept in the source archive until they can be transferred without losing content or provenance.
